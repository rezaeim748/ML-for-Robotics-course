# Machine Learning for Robotics Course

This repository contains a collection of practical assignments and experiments developed as part of the **Machine Learning for Robotics** course. The notebooks cover fundamental and advanced topics in deep learning, robot perception and control, reinforcement learning, and learning-based robotics.

## Repository Structure

The repository covers the following topics:

- **1. PyTorch Fundamentals:** Tensors, autograd, regression, neural networks, and MNIST classification.
- **2. Deep Learning:** Hyperparameter optimization with Optuna, Convolutional Neural Networks (CNNs), and LSTMs for sequential data.
- **3. Robot Control:** MuJoCo simulation, PID control, LQR, stability and controllability analysis.
- **4. Model Predictive Control:** Forward dynamics models, trajectory planning, Random Shooting, and Cross-Entropy Method (CEM).
- **5. Robot Perception:** Sensor noise, Kalman filtering, computer vision, object detection, and tracking.
- **6. SLAM & Generative Models:** Localization, mapping, data association, denoising Autoencoders, and Variational Autoencoders (VAEs).
- **7. Reinforcement Learning Fundamentals:** Markov Decision Processes, Dynamic Programming, Monte Carlo methods, and Q-Learning.
- **8. Deep Reinforcement Learning:** Q-Learning, Deep Q-Networks (DQN), experience replay, and target networks.
- **9. Policy-Based Reinforcement Learning:** REINFORCE, Actor-Critic methods, PPO, and SAC for continuous control.
- **10. Bayesian Optimization:** Gaussian Processes, acquisition functions, controller tuning, and multi-objective optimization.
- **11. Model-Based Reinforcement Learning:** Learned dynamics models, CEM planning, policy distillation, and hybrid model-based/model-free approaches.
- **12. Reinforcement Learning from Images:** Image-based DQN, VAE latent representations, and perception-based state representations.
- **13. Imitation & Offline Reinforcement Learning:** Behavior Cloning, Batch-Constrained Q-Learning (BCQ), and Conservative Q-Learning (CQL).

## Tools and Frameworks

The implementations primarily use **Python, PyTorch, Gymnasium, MuJoCo, TorchRL, NumPy, Matplotlib, OpenCV, Optuna, Ray RLlib, Ax, BoTorch, GPyTorch, and Minari**.
